# Capacitação Interna em Python Básico — AIChE

Este repositório contém o material didático da **Capacitação Interna em Python Básico**, organizada pelo Capítulo Estudantil AIChE. O evento visa fornecer uma base sólida de programação para estudantes de diversas áreas e prepará-los para a capacitação avançada focada no projeto **Chem-E-Car**.

---

## 📅 Estrutura do Minicurso

O conteúdo é dividido em duas partes principais:

1. **Trilha Principal (Aula Ao Vivo - 4 Horas):** Focada na lógica de programação e sintaxe básica do Python, sem necessidade de conhecimento prévio.
2. **Trilha Secundária (Material Assíncrono - Chem-E-Car):** Exercícios práticos e introdução à análise de dados (`pandas` e `matplotlib`) para aplicação na competição do carrinho.

---

## 🚀 Como Acessar e Executar as Aulas

Não é necessário instalar nenhum programa no seu computador. Todo o material é executado diretamente no navegador através do **Google Colab**.

### Passo a passo para os alunos:
1. Clique no botão **"Open in Colab"** referente ao módulo desejado nas tabelas abaixo.
2. Com o notebook aberto, vá no menu superior em **Arquivo** > **Salvar uma cópia no Drive** *(isso cria uma cópia pessoal onde suas alterações e exercícios ficarão salvos)*.
3. Para executar cada bloco de código, clique no ícone de **Play** ao lado dele ou pressione `Shift + Enter`.
